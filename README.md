### Concept Study Notes · A skill for learning by reasoning and doing

**把一份讲义，变成能看懂、能推导、能动手验证的学习路径。**

读完一段解释之后，你能预测下一步的结果吗？能用一个小例子验证公式吗？换一个条件，还能解释它为什么成立吗？

**Concept Study Notes** 是一个面向 Codex 的中文学习笔记 Skill。它把课程讲义、论文和技术资料组织成一条连续的理解路径：从问题出发，用直觉建立认识，通过推导和实现看清机制，再用题目、图解与动手实验检验理解。

这套形式提炼自 CS231n 中文自学笔记与配套练习，也适用于其他数学、编程和技术课程。

## 你会得到什么

| 板块 | 解决的问题 |
| --- | --- |
| 问题与直觉 | 这个知识为什么出现？它在解决什么问题？ |
| 数学与推导 | 符号是什么意思？每一步变形为什么成立？ |
| 实现与对应 | 公式怎样变成代码？中间结果和形状是什么？ |
| 图解与实验 | 参数改变后会怎样？能否亲手验证？ |
| 理解题与解析 | 能否解释、计算、找错和迁移？ |
| 易错与边界 | 哪些条件下会失效？看似正确的做法错在哪里？ |
| 联系与复习 | 如何接上已有知识？怎样判断自己掌握了？ |

## 快速开始

### 安装到 Codex

在 Codex 中使用内置的 Skill Installer，发送：

```text
请使用 $skill-installer 安装这个 GitHub 仓库根目录中的 skill：
https://github.com/liziyan341/concept-study-notes
```

也可以手动克隆到个人技能目录。

**Windows PowerShell**

```powershell
git clone https://github.com/liziyan341/concept-study-notes.git "$env:USERPROFILE\.codex\skills\concept-study-notes"
```

**macOS / Linux**

```bash
git clone https://github.com/liziyan341/concept-study-notes.git "${CODEX_HOME:-$HOME/.codex}/skills/concept-study-notes"
```

如果设置了自定义 `CODEX_HOME`，请使用该目录下的 `skills` 文件夹。目标文件夹已存在时，先检查已有版本，再决定是否更新。

安装后，在下一轮对话中调用 `$concept-study-notes`。若暂未出现在技能列表中，可重新打开 Codex 后再试。

### 第一次使用

把资料放进当前工作区，或在对话中提供资料，然后发送：

```text
用 $concept-study-notes 把这份讲义整理成中文自学笔记。
我的基础是 Python 入门和高中数学。
先做第一章，包含直觉、逐步推导、手算例子、理解题和解析。
```

默认可以直接在对话中输出。需要 Markdown、Notebook、Word、PDF 或互动网页时，请说明载体；具体文件制作能力取决于当前环境提供的工具。

## 笔记长什么样

一节笔记围绕一个问题展开：

```text
这一节要解决的问题
  ↓
直觉：先用具体例子建立认识
  ↓
数学：定义符号、维度、假设，逐步推导
  ↓
实现：把公式对应到代码和中间结果
  ↓
动手：先预测 → 手算或操作 → 验证 → 解释差异
  ↓
理解题：解释机制 → 计算追踪 → 错误诊断 → 迁移应用
  ↓
易错、边界、知识联系和下一步
```

短主题可以合并板块，非数学主题可以用规则、流程和证据替代公式。结构随内容调整。

### 一个小例子：真正理解 Softmax

给定分数 `z = [0, ln(2)]`，温度 `T = 1`。

**先预测**

- 给两个分数都加上 3，概率会变吗？
- 把温度从 1 改为 2，概率会更平均还是更集中？

**再手算**

| 情况 | 指数项 | 概率 |
| --- | --- | --- |
| 原始分数，T = 1 | `[1, 2]` | `[1/3, 2/3]` |
| 共同加 3，T = 1 | `[exp(3), 2exp(3)]` | `[1/3, 2/3]` |
| 原始分数，T = 2 | `[1, √2]` | 约 `[0.4142, 0.5858]` |

**最后解释**

共同平移引入的乘法因子在归一化时抵消；提高温度会缩小相对分数差，使这个例子的分布更平均。

**继续追问**：如果最大分数并列，温度趋近于零时会怎样？为什么“分布更集中”不能直接推出“模型更准确”？

这就是本 Skill 希望形成的学习习惯：**提出预测，展开计算，用结果修正理解，再换一个条件检验。**

## 使用示例

### 从零学习一个概念

```text
用 $concept-study-notes 教我反向传播。
从一个只有两个参数的计算图开始，让我先手算每条路径的梯度，
再对照实现。练习先给提示，把完整解析放在最后。
```

### 把讲义变成可检查的自学资料

```text
用 $concept-study-notes 整理这份 PDF 的第 10–25 个物理页。
按知识点组织笔记，记录来源页码，建立页段与知识点、题号的覆盖表。
出题包含预测输出、错误诊断和改变条件后的迁移题。
```

### 为已有笔记补上动手理解

```text
用 $concept-study-notes 改进这篇 NumPy 笔记，保留原有章节。
为 axis、广播和 reshape 补充小数组手算、形状变化图和反例。
每个实验让我先预测，再运行验证，最后解释差异。
```

### 设计可视化实验

```text
用 $concept-study-notes 设计一个卷积窗口实验。
让我能改变步长和填充，先预测输出尺寸，再观察逐项乘积和最终结果。
请写清核是否翻转；如果无法制作交互，就提供纸笔操作版。
```

## 设计理念

- **从理解目标反推出题。** 题目检验解释、推演、诊断和迁移；干扰项来自真实误区。
- **让图解参与推理。** 图中标清输入输出、维度和假设；实验围绕一个可验证的问题展开。
- **给答案，也给自查依据。** 解析展示关键步骤；简答提供评分要点；数值题说明容差。
- **把来源与补充分开。** 保留资料版本和定位；原创练习与拓展说明身份。
- **让掌握有证据。** 看过答案、完成操作与独立解释分别记录。
