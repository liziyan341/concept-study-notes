# 图解与动手理解

## 根据问题选择表达

| 学习障碍 | 图或实验 | 学习者要做什么 |
| --- | --- | --- |
| 不清楚数据流向 | 输入输出与形状图 | 补齐中间量及每条箭头含义 |
| 不理解局部到整体 | 卷积窗口、逐项累积、计算图 | 移动窗口或沿边计算贡献 |
| 不理解参数影响 | 参数曲线或单变量控件 | 预测方向，再改变一个参数 |
| 混淆两种机制 | 同一输入的并排对比 | 找出差异发生的具体步骤 |
| 公式过于抽象 | 2–4 个元素的数值表格 | 手算后与公式/代码核对 |

使用统一符号和颜色；标出轴、单位、输入输出、关键假设与图例。颜色不作为唯一信息通道。说明示意图的简化条件；不要让二维玩具数据暗示高维真实数据必然有相同行为。

## 实验卡片

每个实验交代：要验证的问题、初始数据、可改变的变量、预测栏、操作步骤、观察指标、解释问题、参考结果、复位方法及边界。保留必要中间量，使学习者能定位差异原因。

交互控件必须改变实际计算并同步更新结果，提供初始值和重置。自由探索之前给一个明确任务；避免只有动画却没有预测或解释问题。随机实验可设种子，并区分随机波动与规律。

## 手算范例：Softmax 的共同平移与温度

问题：共同加常数会改变概率吗？温度改变会发生什么？

给分数 `z=[0, ln(2)]`，使用 `p_i=exp(z_i/T)/sum_j exp(z_j/T)`，限定 `T>0`。

1. **预测**：给两个分数都加 3，概率是否改变？把温度从 1 调到 2，概率更平均还是更集中？
2. **手算**：`T=1` 时指数为 `[1,2]`，概率为 `[1/3,2/3]`。共同加 3 后因子 `exp(3)` 抵消，概率不变。
3. **再试**：`T=2` 时指数为 `[1,sqrt(2)]`，概率约 `[0.4142,0.5858]`，更平均。
4. **解释**：改变的是分数差相对于温度的大小。减去最大分数有利于数值稳定；降低温度通常使分布更集中。
5. **边界**：温度趋零时，唯一最大分数的类别概率趋 1；并列最大时不能说某一个类别独占概率。任意温度改变都不保证模型准确率或概率校准改善。

可视化可以并排显示分数、指数值与概率柱形图；共同平移和温度分别控制，要求先只改变一个量。无交互环境时用上述三组状态的表格完成同一实验。

## 手算范例：卷积窗口

输入 `[[1,2,3],[4,5,6],[7,8,9]]`，核 `[[1,0],[0,-1]]`，步长 1，无填充。先画出左上角窗口并逐项相乘，再移动到下一格。采用深度学习常用的不翻转核的互相关约定，输出为 `2×2`，四项都是 `-4`。

让学习者解释输出尺寸，再改步长或填充重新预测。核约定、边界填充值和步长必须写明；不要把互相关和数学上翻转核的卷积混用。
